# atividade-identidade-visual-itau
🎨 Projeto acadêmico de Identidade Visual inspirado no Itaú, desenvolvido para a atividade de Tipografia e Cores. O projeto apresenta a aplicação de logotipo, paleta de cores, tipografia, escala de fontes e contraste, seguindo princípios de design e identidade visual. Desenvolvido no SENAI com orientação dos professores Raul Porto Lopes e Denani.
